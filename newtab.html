CSS Guide & Class Reference

Core Selectors & Hierarchy

Target these elements to style the core layout.

  • #hero, #clock, #date, #greet — Clock, date & greeting
  • #hh, #mm, #ss — Individual clock digits
  • #searchwrap, #search, #q — Search bar & input
  • #sugg, .sugg-item — Suggestions dropdown rows
  • #board — Bento board container
  • .card — Folder glass container
  • .cat, .cat b — Folder header & title text
  • .grid — Tile grid ([data-cols="1..8"])
  • .tile — Bookmark tile (--c holds its accent color)
  • .box — Icon glass box, .lbl — bookmark label
  • #hiddenDock, .restoreFolder — Hidden folder dock & chips
  • #gear — Settings gear button
  • #cfg, .ctab, .csec — Settings drawer components

CSS Variables & Theming Tokens

Override these on :root to restyle the whole page.

  • --void — page background color
  • --void-gradient — page background gradient
  • --card-tint — folder card glass tint (opaque color)
  • --glass — search bar / gear glass fill
  • --glass-border — card border color
  • --accent / --accent-glow — accent & its glow
  • --ink / --dim / --faint — text colors
  • --font-main / --font-display — typography
  • --tw — tile size, --tile-radius — tile corners
  • --card-radius — card corners
  • --glass-blur / --glass-saturate — backdrop filter
  • --glass-opacity — card translucency (0–1)
  • --glass-border-sheen — specular border strength (0–1)
  • --bg-blur / --bg-dim — wallpaper effects
