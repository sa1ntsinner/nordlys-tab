What's in it

Bookmarks first, then everything around them

Folders you can drag around

Drag a folder anywhere and it shows where it will land. Fitted mode lines rows up edge to edge, and tile size, spacing and width sit in one panel with Undo.

A search box that does a bit more

It uses the engine you picked in Chrome, does math, and takes commands after >.

Icons by brand name

Type a brand, pick a clean icon, and it's saved on your machine.

Profiles and sync

Work and Home as two whole setups. Sync goes through Chrome's own sync, so there's no account of ours.

Nothing leaves your machine

Settings and bookmarks stay in Chrome's storage. It only goes online when you search for an icon or paste an image link.

Each one recolours the sky too. Text stays readable on every background, your own wallpaper included.

Questions

The usual ones

Is it free?
Yes, and the code is open under the MIT licence. If you like it there's a Buy me a coffee link in Settings.
Is the dashboard free too?
Yes, all of it: focus mode, tasks, habits, sounds, the tab stash and every card. If something ever costs money, it will be something that costs money to run, like storage on a server, never what works on your machine.
Do I need an account?
No. Everything is stored in Chrome. Sync, if you turn it on, goes through Chrome's own sync with the Google account you already use.
Can I bring my bookmarks?
Yes. On first open it offers to bring in your Chrome bookmarks, and it imports the HTML file any browser exports. A folder can also follow a Chrome bookmark folder.
Does it slow Chrome down?
The backgrounds are capped at 30 frames a second, drop further when you're idle and stop when the tab is hidden. Still mode paints one frame and stops.
Which browsers?
Chrome, Edge, Brave and other Chromium browsers. A Firefox version is built from the same code and is on its way to Firefox Add-ons; Safari comes after it.
What does it send anywhere?
Only what you ask for: an icon search goes to Iconify, and a pasted image link is fetched. The search box sends nothing until you press Enter. Privacy policy
