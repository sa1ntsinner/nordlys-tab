# Fonts served with the site

- Bodoni Moda (`bodoni-moda*.woff2`), by the Bodoni Moda Project Authors, under the SIL Open Font License 1.1 (`OFL-bodoni-moda.txt`).
- Schibsted Grotesk (`schibsted-grotesk*.woff2`), by the Schibsted Grotesk Project Authors, under the SIL Open Font License 1.1 (`OFL-schibsted-grotesk.txt`).

Both are the Latin subsets of the variable fonts from Google Fonts, served from this folder.
